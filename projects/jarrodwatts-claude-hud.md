# jarrodwatts/claude-hud

**GitHub**: https://github.com/jarrodwatts/claude-hud

**Language**: JavaScript

## Description

A Claude Code plugin that shows what's happening - context usage, active tools, running agents, and todo progress. Always visible below your input.

**What You See:**
- Project path - Know which project you're in
- Context health - Know exactly how full your context window is
- Tool activity - Watch Claude read, edit, and search files
- Agent tracking - See which subagents are running
- Todo progress - Track task completion in real-time

## AI Summary

Claude HUD is a Claude Code plugin that provides real-time visibility into your AI coding sessions. It displays context usage, active tools, running agents, and todo progress directly in the terminal using Claude Code's native statusline API. No separate window or tmux required.

## Installation

```
/plugin marketplace add jarrodwatts/claude-hud
/plugin install claude-hud
/claude-hud:setup
```
