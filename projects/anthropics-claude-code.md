# Claude Code

**Claude Code is an agentic coding tool that lives in your terminal**

> Understands your codebase, and helps you code faster by executing routine tasks, explaining complex code, and handling git workflows - all through natural language commands.

## 核心特点

- 🖥️ **终端原生** - 直接在命令行中使用
- 📚 **代码库理解** - 理解整个项目的上下文
- 🔄 **Git 集成** - 自动处理版本控制工作流
- 💬 **自然语言** - 用日常语言描述需求

## 技术栈

- Shell
- Anthropic Claude API
- Git 集成

## 适用场景

- 日常编码任务
- 代码解释与重构
- 自动化工作流
- 代码审查
