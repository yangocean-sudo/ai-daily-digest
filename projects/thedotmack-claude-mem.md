## Description

A Claude Code plugin that automatically captures everything Claude does during your coding sessions, compresses it with AI (using Claude's agent-sdk), and injects relevant context back into future sessions.

## AI Summary

claude-mem solves one of the most significant limitations of AI coding assistants: context window constraints. This innovative plugin:

1. **Session Recording**: Captures all interactions, file changes, and decisions during coding sessions
2. **AI Compression**: Uses Claude's agent-sdk to intelligently compress session history while preserving key information
3. **Context Injection**: Automatically retrieves and injects relevant past context into new sessions
4. **Long-term Memory**: Enables Claude Code to maintain continuity across multiple disconnected sessions

This is particularly valuable for long-running projects where context would otherwise be lost between sessions.

## Use Cases

- Long-term software development projects
- Complex refactoring tasks spanning multiple sessions
- Maintaining context across days or weeks of work
- Team collaboration with shared project context
- Building up institutional knowledge in AI-assisted workflows
