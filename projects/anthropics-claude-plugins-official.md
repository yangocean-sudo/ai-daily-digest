这是 Anthropic 官方管理的 Claude Code 插件目录，收集了高质量的 Claude Code 插件。插件目录分为两部分：/plugins 目录包含 Anthropic 内部开发和维护的插件，/external_plugins 目录包含来自合作伙伴和社区的第三方插件。
