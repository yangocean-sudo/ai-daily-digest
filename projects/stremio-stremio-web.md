# Stremio Web

**Stremio - Freedom to Stream**

> Stremio 是一个流行的流媒体内容聚合平台，让用户可以在一个地方发现和观看来自多个来源的视频内容。

## 核心特点

- 📺 **内容聚合** - 整合多个流媒体源
- 🔌 **插件扩展** - 支持社区插件
- 🌐 **Web 优先** - 现代 Web 技术构建
- 📱 **跨平台** - 支持多种设备和平台

## 技术栈

- JavaScript
- React
- Web 流媒体技术

## 适用场景

- 视频内容发现
- 流媒体聚合
- 个人媒体中心
