## Description

This is the official MCP (Model Context Protocol) server for data.gouv.fr, the French national Open Data platform. It enables AI chatbots to interact with France's open datasets through natural conversation, allowing users to search, explore, and analyze public data using AI assistants.

## Key Features

- Official integration with data.gouv.fr
- Model Context Protocol (MCP) implementation
- Natural language interaction with open data
- Dataset search and exploration capabilities
- Data analysis through AI chatbots
- Government-backed open data initiative
