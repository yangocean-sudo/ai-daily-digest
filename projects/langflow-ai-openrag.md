## Description

OpenRAG is a comprehensive, single package Retrieval-Augmented Generation platform built on Langflow, Docling, and Opensearch.

## AI Summary

OpenRAG offers a complete RAG solution in a single deployable package:

1. **Document Processing**: Built-in support for various document formats via Docling
2. **Vector Search**: Powered by Opensearch for fast, scalable retrieval
3. **Workflow Builder**: Visual interface for designing RAG pipelines via Langflow
4. **Single Package**: Everything needed for RAG in one installation
5. **Production Ready**: Designed for enterprise deployments

The platform abstracts away the complexity of setting up document processing, embedding generation, vector storage, and LLM integration.
