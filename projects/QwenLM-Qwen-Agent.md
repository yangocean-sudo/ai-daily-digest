## Description

Qwen-Agent is a comprehensive agent framework developed by Alibaba's Qwen team. Built on top of Qwen 3.0, it provides a complete toolkit for building AI agents with advanced capabilities including function calling, Model Context Protocol (MCP) support, code interpretation, Retrieval-Augmented Generation (RAG), and even a Chrome extension for browser integration.

## Key Features

- Function Calling support
- Model Context Protocol (MCP) integration
- Code Interpreter capabilities
- RAG (Retrieval-Augmented Generation)
- Chrome extension for browser automation
- Built on Qwen 3.0 foundation
