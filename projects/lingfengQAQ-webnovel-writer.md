## Description

Webnovel-writer is a specialized system built on top of Claude Code designed specifically for long-form creative writing. It addresses two major challenges in AI-assisted writing: maintaining consistency over very long narratives (the "forgetting" problem) and avoiding AI hallucinations that break story coherence. The system supports serialized novels up to 2 million words.

## Key Features

- Claude Code integration
- Long-form content consistency management
- Anti-hallucination mechanisms
- Support for 2 million word projects
- Serialized novel workflow
- Memory management for long narratives
