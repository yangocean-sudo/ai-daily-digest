# FossFLOW

**Make beautiful isometric infrastructure diagrams**

> An agentic skills framework & software development methodology that works.

## 核心特点

- 🎨 **等距视角** - 独特的 3D 等距图表风格
- ☁️ **多云支持** - 支持 AWS、Azure、GCP 等主流云服务商图标
- 📝 **简单配置** - 通过代码或 YAML 定义架构
- 🖼️ **高质量输出** - 适合技术文档和演示文稿

## 技术栈

- TypeScript
- SVG/Canvas 渲染
- 云服务商图标库

## 适用场景

- 云架构文档
- 技术演示
- 系统架构设计
- 基础设施可视化
