# 🧠 AI Daily Digest

每日自动生成的新闻 + GitHub Trending 摘要，用 Obsidian 阅读。

## 板块

- 🔥 **GitHub Trending** — 每日热门开源项目 + AI 总结
- 🌍 **地缘政治** — 国际局势要闻
- 🤖 **科技 / AI** — AI、科技行业动态
- 📈 **财经市场** — 股市、加密货币、宏观经济
- 🏢 **商业动态** — 创业、融资、企业新闻

## 结构

```
daily/          每日汇总 (YYYY-MM-DD.md)
projects/       GitHub 项目单页 (双链)
weekly/         每周总结
```

## 使用

1. Clone 本仓库
2. 用 Obsidian 打开文件夹
3. 推荐安装 Copilot for Obsidian 插件，可以对笔记内容提问

自动更新：每天 UTC 8:30 由 Mochi 🍡 推送
