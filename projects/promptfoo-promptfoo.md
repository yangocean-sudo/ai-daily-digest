## Description

Test your prompts, agents, and RAGs. Red teaming/pentesting/vulnerability scanning for AI. Compare performance of GPT, Claude, Gemini, Llama, and more. Simple declarative configs with command line and CI/CD integration.

## AI Summary

promptfoo is a comprehensive testing framework specifically designed for LLM applications. It addresses a critical gap in AI development by providing:

1. **Prompt Testing**: Systematic evaluation of prompt variations to optimize performance
2. **Red Team Security**: Vulnerability scanning for AI systems to identify potential exploits
3. **Model Comparison**: Side-by-side evaluation of different LLM providers (OpenAI, Anthropic, Google, etc.)
4. **CI/CD Integration**: Automated testing pipelines for continuous deployment
5. **RAG Evaluation**: Specialized tools for testing Retrieval-Augmented Generation systems

The framework uses declarative YAML configurations, making it easy to version control test suites alongside application code.

## Use Cases

- Evaluating prompt variations before production deployment
- Automated regression testing for AI features
- Security auditing of LLM applications
- Benchmarking different model providers
- Testing RAG pipeline accuracy
