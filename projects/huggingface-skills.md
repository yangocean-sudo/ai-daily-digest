## AI 总结
Hugging Face Skills 是为 AI/ML 任务（如数据集创建、模型训练和评估）定义的技能集合。这些技能采用标准化的 Agent Skill 格式，兼容所有主流编码 Agent 工具（OpenAI Codex、Claude Code、Google Gemini CLI、Cursor）。

该仓库包含多个实用技能：HF CLI 操作、数据集管理、模型评估、Job 管理、模型训练（支持 SFT、DPO、GRPO 等方法）、论文发布、工具构建、Trackio 实验跟踪等。对于使用 Hugging Face 生态系统的 ML 工程师来说，这些技能大大简化了日常工作流程。
