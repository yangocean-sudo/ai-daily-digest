## Description

HVE-core is Microsoft's Hypervelocity Engineering component library, designed to enhance AI-assisted development workflows. It provides a curated collection of instructions, prompts, agents, and skills that help developers maximize the effectiveness of GitHub Copilot and other AI coding assistants from project initialization through ongoing development.

## Key Features

- Hypervelocity Engineering components
- Pre-built prompts and instructions
- AI agent configurations
- Skills library for Copilot optimization
- PowerShell-based tooling
- Project upgrade utilities
