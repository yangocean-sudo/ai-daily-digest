# GitNexus

**Zero-Server Code Intelligence Engine**

> GitNexus is a client-side knowledge graph creator that runs entirely in your browser. Drop in a GitHub repo or ZIP file, and get an interactive knowledge graph with a built in Graph RAG Agent. Perfect for code exploration.

## 核心特点

- 🌐 **纯浏览器运行** - 无需服务器，保护代码隐私
- 📊 **交互式知识图谱** - 可视化代码结构与依赖关系
- 🤖 **内置 Graph RAG Agent** - 智能问答与代码分析
- 📁 **支持多种格式** - GitHub 仓库、ZIP 文件直接导入

## 技术栈

- TypeScript
- 浏览器原生 API
- 知识图谱可视化
- Graph RAG 技术

## 适用场景

- 代码库探索与理解
- 技术文档生成
- 代码审查辅助
- 开源项目学习
