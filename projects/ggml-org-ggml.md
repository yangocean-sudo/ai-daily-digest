# GGML

**Tensor library for machine learning**

> GGML 是一个为机器学习优化的张量库，由 llama.cpp 的作者开发，专注于在消费级硬件上高效运行大型语言模型。

## 核心特点

- 🚀 **高性能** - 针对 CPU 优化的张量计算
- 💾 **量化支持** - 多种量化格式减少内存占用
- 🔧 **跨平台** - 支持多种操作系统和硬件
- 🦙 **llama.cpp 基础** - 众多本地 LLM 项目的底层库

## 技术栈

- C/C++
- SIMD 优化
- 量化算法

## 适用场景

- 本地 LLM 部署
- 边缘设备推理
- 模型量化压缩
- 自定义 ML 运行时
