## Description

This groundbreaking project demonstrates how everyday WiFi routers can be repurposed for advanced sensing capabilities using signal processing and machine learning. By analyzing WiFi signal distortions caused by human bodies, the system can estimate poses, monitor breathing and heart rates, and detect presence — all without cameras or wearable devices.

## Key Features

- Real-time human pose estimation from WiFi signals
- Vital sign monitoring (breathing, heart rate)
- Presence detection
- Privacy-preserving (no cameras required)
- Works with commodity WiFi hardware

## AI Summary

WiFi DensePose represents a paradigm shift in human sensing technology. By leveraging the radio frequency (RF) signals that permeate our environments, it eliminates the need for cameras while maintaining rich sensing capabilities. This has profound implications for:

- **Low-cost deployment**: Utilizing existing WiFi infrastructure rather than installing specialized sensors
