### 4. [ruvnet/ruvector](https://github.com/ruvnet/ruvector) ⭐+290 今日
**Stars**: 2k | **Forks**: 204 | **语言**: Rust

RuVector 是一个高性能、实时、自学习的向量图神经网络和数据库，使用 Rust 构建。

**核心特性：**
- 自学习 GNN：搜索结果根据使用自动改进
- 46 种注意力机制（Flash、线性、图、双曲、最小割门控）
- Cypher 图查询（兼容 Neo4j）
- PostgreSQL 扩展，提供 230+ SQL 函数
- 本地 LLM 运行时（ruvllm）—— 无需云 API
- RVF 认知容器：单个文件 125 毫秒内作为微服务启动
- 跨域迁移学习
- 次线性求解器：O(log n) 的 PageRank 和谱方法

**为什么重要：** 与传统返回静态结果的向量数据库不同，RuVector 使用 GNN 层从每次查询中学习。在 10 万次查询后召回率提高 12.4%，同时保持 <1 毫秒延迟。为 Cognitum 自主 AI 硬件平台提供动力。
