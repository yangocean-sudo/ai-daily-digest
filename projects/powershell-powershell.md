# PowerShell

**PowerShell for every system!**

> 微软官方开源的 PowerShell 跨平台版本，支持 Windows、Linux 和 macOS。

## 核心特点

- 💻 **跨平台** - Windows、Linux、macOS 原生支持
- 🎯 **面向对象** - 基于 .NET 的对象管道
- 🔧 **强大脚本** - 系统管理和自动化的利器
- 🌐 **远程管理** - 强大的远程执行能力
- 📦 **模块生态** - 丰富的 PowerShell Gallery 资源

## 技术栈

- C#
- .NET
- WMI/CIM
- REST API

## 适用场景

- 系统管理自动化
- DevOps 工作流
- 云资源管理
- 安全审计脚本
