## Description

OpenSandbox offers multi-language SDKs, unified sandbox APIs, and Docker/Kubernetes runtimes for scenarios like Coding Agents, GUI Agents, Agent Evaluation, AI Code Execution, and RL Training.

## Key Features

- Multi-language SDK support
- Unified sandbox APIs
- Docker/Kubernetes runtime integration
- Designed for AI agent scenarios
- Support for RL training environments
